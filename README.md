# TESORO POINT website

Static site for GitHub Pages. No build step.

Files: `index.html`, `styles.css`, `script.js`, `assets/tesoro-station.jpg`, `.nojekyll`.

## Settings (top of `script.js`)
- `DRIVE_FILE_ID`: Google Drive video ID. Share the video as "Anyone with the link can view".
- `FORM_ENDPOINT`: FormSubmit endpoint. The first submission triggers an activation email; confirm it, then send a test enquiry.

## Publish on GitHub Pages
1. Upload the CONTENTS of this folder to the root of the `tesoro-point-website` repository.
2. Settings > Pages > Deploy from a branch > `main` > `/ (root)`.
